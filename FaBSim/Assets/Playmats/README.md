# Playmat artwork

These playmats and their thumbnails come from `public/playmats` in [Talishar-FE](https://github.com/Talishar/Talishar-FE). The catalog follows the public `PLAYER_PLAYMATS` list in `src/features/options/cardBacks.ts`.

The artwork files are unchanged and retain their embedded credits. `TALISHAR-LICENSE` is the license file from the source repository.
