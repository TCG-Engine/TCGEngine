Each real match is played twice by the bots (deck A first, then deck B first), so a pair's bot games are about twice its real matches. Real game counts come from Best-of-3 scores, so they are larger. The range under Real win % is a 95% Wilson interval on those real games: where it is wide, the real number is uncertain too.
Archetype = leader + base bucket (30HP / Force / Splash, rare bases by name). Deck style is the bot's piloting profile: the curated fixture's label where one exists, otherwise the automatic classifier.
