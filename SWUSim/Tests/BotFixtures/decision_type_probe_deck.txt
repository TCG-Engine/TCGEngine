# NOT a Premier-pool deck and not meant to be one. This is a deliberate PROBE list whose only job is

#
# Why the probe has to leave the Premier pool: a repo-wide sweep of DecisionQueueController::
# AddDecision call sites shows exactly which cards emit each exotic type, and for three of them every
# emitter is outside JTL/LOF/SEC/IBH/LAW/ASH:
#
#   SCRY          — DoScry() (SWUSim/Custom/GameLogic.php:14145) has exactly TWO callers repo-wide,

#                   SOR_236 is the cheap, repeatable raiser: 1 cost, and its trigger is
#                   "When Played/On Attack", so it fires again on every attack.
#   REVEALARRANGE — one emitter repo-wide: SOR_152 For a Cause I Believe In.
#   NAMETRAIT     — one emitter repo-wide: HMW_108 The First Legion (a PREVIEW set, so it is not in
#                   Premier either). On Attack, so it repeats.
#
# The leader/base/filler are lifted from the already-green premier_deck_a.txt skeleton (SOR_009 /
# SOR_022 and its cheap Heroism core) precisely so that any failure this fixture produces is
# attributable to the four probe cards and not to an untested shell.
